# 📊 Sales Summary with SQLite and Python

This project demonstrates how to connect to a **SQLite database using Python**, run basic **SQL queries**, and visualize the results using **pandas** and **matplotlib**.

## 🧾 Objective

- Create a simple SQLite database containing sales records.
- Run an SQL query to summarize:
  - Total quantity sold
  - Total revenue generated
- Display the output using `print()` and a **bar chart**.
